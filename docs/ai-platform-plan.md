# BotOS AI Platform 統合計画 (Workers AI 構想)

## 1. 概要とコンセプト
Cloudflare が提供する「Workers AI」や「AI Gateway」のように、BotOS 上で動作する Discord Bot やプラグインから、サーバーレスかつ安全に生成AI（LLM、埋め込み、画像認識など）を呼び出し・制御できるようにするための統合計画。

外部の重いライブラリを直接各Botに個別インストールさせるのではなく、BotOS の共通基盤レイヤーを通じて、標準化されたAPIインターフェースとレート制限・キャッシュ・AST検証を提供します。

---

## 2. コア機能構想

### 2.1 BotOS AI Gateway (推論プロキシ & キャッシュ)
- **マルチプロバイダ対応**: Gemini API、Cloudflare Workers AI、OpenAI 互換エンドポイントを統一インターフェースで抽象化。
- **インテリジェントキャッシュ**: 同一または類似の質問・コマンド実行結果をキャッシュし、API利用コストとレイテンシを削減。
- **レート制限 & トークン監視**: サーバー（ギルド）ごと、またはユーザーごとの1日あたりの消費トークン数・呼び出し回数の上限制御。
- **ログ & メトリクス**: プロンプト実行時間、消費トークン数、エラー率をWebコンソール上で可視化。

### 2.2 AST サンドボックス連携 (プラグインからの安全なAI呼び出し)
- **隔離された標準API (`botos.ai`)**:
  - `botos.ai.generate_text(prompt, model="default")`
  - `botos.ai.summarize(text)`
  - `botos.ai.embed(text)`
- **安全規約**: プラグイン開発者が勝手に外部HTTPリクエスト（`requests`, `httpx` 等）を発行するのを防ぎ、プラットフォームが提供する `botos.ai` メソッド経由でのみ実行を許可。
- **自動プロンプトサニタイズ**: 意図しないプロンプトインジェクションや機密情報の漏洩を防ぐフィルタリング。

### 2.3 Web コンソールでの AI 拡張機能
- **自然言語によるコマンド・プラグイン生成**:
  - Web UI 上で「〜をするコマンドを作って」と入力すると、AST サンドボックス規約を満たす安全な Python プラグインコードを自動生成してエディタに展開。
- **AST エラーの自動修正サジェスト**:
  - 禁止構文（危険な属性アクセスやインポート）が含まれる場合に、AIが安全な代替コード（例: `botos.api` や組み込み関数の利用）を提示。
- **対話型デバッグ & 実行シミュレーター**:
  - Web 上でDiscordのモックInteractionを投げ、AIの返答やコマンド挙動を実機なしでテスト。

## 3. ロードマップ & フェーズ分け

| フェーズ | 開発項目 | 主な成果物 |
| :--- | :--- | :--- |
| **Phase 1** | AI Gateway のコア設計 | バックエンドでのプロバイダ接続層、キャッシュ機構、レート制限 |
| **Phase 2** | プラグイン SDK 統合 | `botos.ai` API の提供、サンドボックス内での利用認可 |
| **Phase 3** | Web UI アシスタント | プロンプト入力によるコマンド生成、ASTエラーの自動修正サジェスト |
| **Phase 4** | メトリクス & ガバナンス | ギルドごとのトークン消費グラフ、監査ログ画面への推論ログ統合 |
