## 🛠️ 開発ルール（クイックリファレンス）

1. **ブランチ命名規則**:
   - `feature/web-<task>`
   - `feature/api-<task>`
   - `feature/core-<task>`
   - `feature/plugin-<task>`
   - `fix/<bug-name>`
2. **コミット / PR**:
   - PR は `dev`（または `main`）向けに作成
   - PR 説明欄に「動作確認した内容 / スクリーンショット / 未確認項目」を明記
   - `make check` (ruff) をパスしていること
3. **セキュリティ**:
   - `.env` や秘密情報（Bot Token、Client Secret）は絶対にコミットしない
