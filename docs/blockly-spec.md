# BotOS — Blockly (ノーコード) 設計仕様書

Google Blocklyを活用し、Scratchライクな操作感でDiscord Botのロジックを直感的に構築するための設計。

## 1. カテゴリ構成

```text
[イベント] (Events)
  ├── スラッシュコマンドが実行されたとき
  ├── メンバーが参加したとき
  └── メッセージが送信されたとき

[Discordアクション] (Discord Actions)
  ├── 返信メッセージを送信する
  ├── チャンネルにメッセージを送信する
  ├── ユーザーをキックする / バンする
  └── ロールを付与する / 剥奪する

[Discordデータ] (Discord Data)
  ├── 実行者 (User)
  ├── コマンド引数
  ├── 現在のチャンネル
  └── 対象ギルド

[制御・ロジック] (Control & Logic)
  ├── もし〜なら / でなければ (if-else)
  ├── 比較 (==, !=, <, >)
  └── 論理演算 (and, or, not)

[変数・ストレージ] (Variables & Storage)
  ├── 一時変数
  └── サーバー専用データ保存 / 取得
```

## 2. ワークスペースの保存とコード生成

- **保存形式:** Blocklyのワークスペース状態（ブロック配置、座標、接続情報）をJSONオブジェクトとして `.botos.json` の `workspace` フィールドにそのまま保存。
- **コードジェネレータ:** Webパネル上でBlockly JavaScript/Pythonジェネレータを実行し、サンドボックス互換の安全な実行スクリプトを自動生成する。
